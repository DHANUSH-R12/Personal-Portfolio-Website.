# Personal Portfolio Website

Full Stack Development Task – Personal Portfolio Website.

## Technologies
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL

## Features
- Responsive layout
- Mobile navigation
- About section
- Skills section
- Projects section
- Contact form
- MySQL database integration
- Form validation
- Modern UI

## Setup in WAMP
1. Copy the `personal_portfolio` folder into:
   `C:\wamp64\www\`
2. Start Apache and MySQL in WAMP.
3. Open phpMyAdmin:
   `http://localhost/phpmyadmin`
4. Import `database.sql`.
5. Open:
   `http://localhost/personal_portfolio/`
